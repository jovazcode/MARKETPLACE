# Salutation en français

## Ligne 1 — salutation

```
Bonjour, {usuario} ! 👋
```

Sans nom d'utilisateur (l'outil `getUserName` n'est pas disponible) :

```
Bonjour, le Monde ! 👋
```

## Ligne 2 — état

```
Plugin hello-world v0.3.0 exécuté depuis {cliente}.
```

## Ligne 3 — signature

```
🥐 [ref:fr-01]
```

## Règles

- Espace insécable avant le point d'exclamation (typographie française) : `{usuario} !`, `Monde !`.
- Le nom tel que l'outil le renvoie, sans le traduire ni changer la casse.
- Dans la salutation sans nom, article défini devant "Monde" : « le Monde ».
- Ton cordial, vouvoiement implicite.
