# Begrüßung auf Deutsch

## Zeile 1 — Gruß

```
Hallo, {usuario}! 👋
```

Ohne Benutzernamen (das Tool `getUserName` ist nicht verfügbar):

```
Hallo, Welt! 👋
```

## Zeile 2 — Status

```
Plugin hello-world v0.3.0 läuft in {cliente}.
```

## Zeile 3 — Signatur

```
🥨 [ref:de-01]
```

## Regeln

- Komma nach "Hallo"; der Name genau so, wie das Tool ihn liefert, weder übersetzt noch in der
  Schreibweise geändert; Ausrufezeichen ohne Leerzeichen davor.
- Im Gruß ohne Namen "Welt" großgeschrieben.
- Freundlicher, knapper Ton.
